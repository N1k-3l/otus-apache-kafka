## Homework 3

Перенёс проект в докер, добавил UI для более удобного отображения. 2 приложения как в задании. Producer пишет по 5 сообщений и коммитит их, потом пишет по 2 сообщения и абортит. Consumer читает в зависимости от переданного `isolation.level`: при `read_committed` читает только из закоммиченных транзакций, при `read_uncommitted` читает всё.
